SK MOTOR BIKE & CAR — WEBSITE STARTER
======================================

Files:
- index.html  : main website
- style.css   : responsive styling
- script.js   : mobile menu and WhatsApp enquiry form
- showroom.jpg: add your showroom photo here (optional)

HOW TO PREVIEW
1. Extract this ZIP.
2. Keep index.html, style.css and script.js in the same folder.
3. Open index.html in a browser.
4. To show your uploaded showroom photo in the hero area, copy the shop photo into this folder and name it exactly: showroom.jpg
